# Personal Reddit Post Aggregator

A read-only Python utility that aggregates and categorizes posts across public tech and business subreddits into an internal feed for consolidated reading.

## Features
* **15-Minute Feed Polling:** Queries target subreddit new feeds at non-intrusive rate limits.
* **Category Filtering:** Sorts posts into interest categories using customizable keyword rules.
* **Periodic Comment Tracking:** Pulls top-level comment threads from saved posts every 45 minutes.
